# 📁 Projets HTML – Mini Applications Web

Un ensemble de 4 mini-projets réalisés en HTML, CSS et JavaScript vanilla, sans dépendances externes.

---

## 📂 Structure du projet

```
├── calculatrice.html        # Calculatrice scientifique
├── Calculatrice-Simple.html # Calculatrice basique à deux opérandes
├── IMC.html                 # Calculateur d'IMC
└── permutation.html         # Permutation de deux champs texte
```

---

## 🔢 1. Calculatrice Scientifique — `calculatrice.html`

Une calculatrice avec interface graphique style clavier physique.

**Fonctionnalités :**
- Opérations de base : `+`, `-`, `*`, `/`
- Racine carrée (`√`)
- Mise au carré (`x²`)
- Bouton Effacer (`C`)
- Évaluation de l'expression complète via `eval()`

**Technologies :** HTML, CSS Grid, JavaScript  
**Lancer :** Ouvrir `calculatrice.html` dans un navigateur

---

## ➕ 2. Calculatrice Simple — `Calculatrice-Simple.html`

Une calculatrice minimaliste à deux champs de saisie.

**Fonctionnalités :**
- Saisie de deux nombres séparés
- Opérations : `+`, `-`, `*`, `/`
- Protection contre la division par zéro

**Technologies :** HTML, JavaScript  
**Lancer :** Ouvrir `Calculatrice-Simple.html` dans un navigateur

---

## ⚖️ 3. Calculateur d'IMC — `IMC.html`

Un outil de calcul de l'Indice de Masse Corporelle (IMC) avec affichage du résultat coloré.

**Fonctionnalités :**
- Saisie du poids (kg) et de la taille (m)
- Calcul automatique de l'IMC
- Classification avec code couleur :
  - 🟡 Insuffisance pondérale `< 18.5`
  - 🟢 Corpulence normale `18.5 – 24.9`
  - 🟡 Surpoids `25 – 29.9`
  - 🔴 Obésité modérée à morbide `≥ 30`
- Validation des entrées

**Technologies :** HTML, CSS, JavaScript  
**Lancer :** Ouvrir `IMC.html` dans un navigateur

---

## 🔄 4. Permutation — `permutation.html`

Un utilitaire simple pour échanger le contenu de deux champs texte.

**Fonctionnalités :**
- Deux champs de saisie (Texte A / Texte B)
- Bouton **Permuter** qui échange les valeurs via une variable temporaire

**Technologies :** HTML, JavaScript  
**Lancer :** Ouvrir `permutation.html` dans un navigateur
